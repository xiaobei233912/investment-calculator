## 已知边界

- 小数周期使用广义年金模型，不是实际扣款日历。
- 不足一个周期时可能产生多个收益率解，界面明确提示无法唯一求解。
- 金额上限 1e15；期限上限 1,000 年；年化收益率范围为大于 −100% 至 10,000%。极端病态参数可能无法在 Number 精度下可靠反解。
- 当前为本地独立 Web 应用，无云部署及小红书平台适配。
