# 投资计算器

一个中文、Mobile First 的独立 Web 投资工具，使用 React、TypeScript（strict）、Vite 与原生 SVG。支持五种求解模式、资产增长图及默认折叠的年度明细。没有账户、数据库、平台 API 或其他金融调整项。

参考 [Calculator.net Investment Calculator](https://www.calculator.net/investment-calculator.html) 的核心求解交互及基准案例；代码、中文文案、样式与图表均独立实现，未复制其代码或视觉资产。

## 安装与运行

建议 Node.js 22.12+（或满足 Vite 7 要求的 Node 20.19+），使用 npm。仓库包含 package-lock.json，之后安装请优先使用 `npm ci`。

```sh
npm ci
npm run dev
```

打开终端显示的本机地址，默认 `http://127.0.0.1:5173/`。

```sh
npm test             # Vitest 自动化测试
npm run test:watch   # 持续测试
npm run typecheck    # TypeScript strict 检查
npm run build        # 类型检查 + 生产构建，输出 dist/
npm run preview      # 本地预览生产构建，默认 4173
```

`dist/` 可由任意静态 HTTP 服务部署。本项目无后端、环境变量、密钥、数据库或外部字体请求。当前交付为独立本地 Web 工程，未配置云部署或小红书适配。

## 五种模式

| 模式       | 未知数 | 方法                                                           |
| ---------- | ------ | -------------------------------------------------------------- |
| 算期末金额 | FV     | 复利本金 + 普通/先付年金终值                                   |
| 算追加投入 | PMT    | `(FV − P × G) / A`                                             |
| 算收益率   | r      | 在对数增长率坐标下搜索，扩展上界并二分求根                     |
| 算初始本金 | P      | `(FV − PMT × A) / G`                                           |
| 算投资期限 | t      | 零收益解析反解；其他情况检查方向、平衡点及渐近线后进行有界二分 |

每次只显示其余四个数值输入，以及复利频率、追加投入频率、追加投入时点。默认展示基准案例的已计算结果。编辑参数或切换模式后清除旧结果，点击「开始计算」才重新计算。切换模式时保留未经截断的反解数值，避免结果四舍五入导致往返误差。

```text
  components/

    Results.tsx              主结果、摘要、年度表
  tests/
    investmentEngine.test.ts
    investmentFormatting.test.ts
  App.tsx                    表单、模式切换及页面状态
  main.tsx
  styles.css
```

核心入口：`calculateInvestment(input: InvestmentInput): CalculationOutcome`。输入是可辨识联合类型：`mode` 对应的未知变量不需要传入。成功返回五个完整参数、被求解数值、期末金额、累计追加投入、累计收益、年度明细和图表数据；失败返回 `{ ok: false, error: { code, message, field? } }`。

`calculateFutureValue(plan)` 是校验后的数值终值接口；非法参数会抛出携带 `detail` 的 Error。普通 UI / 平台适配器应使用返回结构化错误的 `calculateInvestment`。

```ts
import { calculateInvestment } from "./src/lib/investmentEngine";

const outcome = calculateInvestment({
  mode: "endAmount",
  startingAmount: 20000,
  contribution: 1000,
  returnRate: 0.06, // 引擎使用小数；UI 的 6 只在输入适配层除以 100
  years: 10,
  compoundFrequency: "annually",
  contributionFrequency: "monthly",
  contributionTiming: "end",
});
```

引擎只依赖 TypeScript/JavaScript Number 与 Math，不引用 React、DOM、Intl 或人民币单位。引擎内部不使用 `round`、`toFixed` 或中间截断；舍入只发生在格式化层。

## 金融口径

令 P 为本金、PMT 为每次追加投入、r 为名义年化收益率（6% = 0.06）、t 为年数。

- 每年复利：`AnnualFactor = 1 + r`。
- 每月复利：月利率 `r / 12`，`AnnualFactor = (1 + r / 12)^12`。UI 输入仍是年化利率，不能当成月利率或有效年收益率。
- 每月追加：`p = 12`，PMT 为每月金额。
- 每年追加：`p = 1`，PMT 为每年金额。
- 周期有效收益率：`i = AnnualFactor^(1/p) − 1`。
- 总周期数：`N = t × p`，`G = (1+i)^N`。
- 期末投入：`A = (G−1)/i`，每月月底或每年年末投入。
- 期初投入：`A = (G−1)/i × (1+i)`，每月月初或每年年初投入。
- 终值：`FV = P × G + PMT × A`。
- 零收益：`FV = P + PMT × N`。
- 累计追加投入：`PMT × N`；累计投入本金：`P + PMT × N`。
- 累计收益：`FV − P − PMT × N`。

实现使用 `log1p` / `expm1` 计算增长和年金系数。收益率恰为 0 时直接采用极限值；非常接近 0 但不为 0 时使用稳定函数保留精度，不粗略归零。

### 小数期限与年度明细

统一将年金公式延伸到实数 `N = t × p`，不把周期数取整，也不擅自添加或删除一整笔投入。这是五种模式保持一致的数学约定。对于非整数周期，`PMT × N` 为模型中的比例投入，并不代表一张实际逐笔扣款时间表。

例如每月投入、10.42 年使用 N = 125.04；10.5 年使用 N = 126。最后不足一年以最后一行显示。收益率未知且不足一个投入周期时，普通年金的数学延伸可能不再随利率单调，甚至存在两个根；引擎先分段检查，无法唯一或可靠确定时返回中文错误。

年度明细每年直接调用同一个终值函数计算，不另外实现现金流公式。「当年投入」仅包括追加投入，初始本金在摘要单列；当年收益为 `本期末资产 − 上期末资产 − 当年追加投入`。图表与表格共用年度节点，最后一个节点直接复用主结果数值，从而保证三个终值严格相等。没有月度明细。

## 数值求解与错误处理

- 本金、目标、每期投入以及输出金额支持 0 至 `1e15`（1,000 万亿元）。累计投入本金也遵守该限制。
- 期限支持大于 0 至 1,000 年，最多 1,000 行年度明细。
- 两种复利模式统一支持大于 −100% 至 10,000% 的名义年化收益率。每月复利理论上还存在低于 −100% 的可计算名义利率，但本工具不开放此范围。
- 收益率搜索从 10% 上界开始按对数增长率扩展；下界采用大于 −100% 的可表示数。最大 240 次二分；相对终值容差 `2e-13`。逼近浮点分辨率时额外检查残差，不能可靠收敛则报告错误。
- 检查负金额反解、期限方向错误、负利率渐近线、无现金流、平衡资产及仅一次期末投入等无解/不唯一情形。
- 不足一个周期的非单调收益率反解，先以最多 160 次黄金分割定位最小点，再检查两侧并二分；不随意选取多个可行收益率之一。
- 搜索期间允许内部正无穷作为「超过目标」的比较信号，但所有公开结果均检查为有限数且在支持范围内。超出范围、下溢导致无法可靠反解、未收敛等情况返回错误，不展示 NaN、Infinity 或 undefined。
- 极端负收益、极长期间等病态问题可能丢失反推本金所需的信息；浮点数无法保证任意极端参数下可逆，不伪造确定结果。

## 数字输入与移动端

金额使用数字键盘提示，可粘贴规范千分位金额。编辑期间不插入逗号、不重写小数或强制金额取整。失焦后显示千分位及适当小数位，底层字符串保留完整值；重新编辑时显示完整精度。金额结果两位小数，收益率两至四位小数，年份最多两位；期限另显示约几年几个月。

五个模式支持窄屏横向滚动、键盘左右键及 Home/End。主容器最大 680px；小屏摘要逐行排列；年度明细默认折叠，表格可横向滚动。SVG 图表没有第三方图表依赖，滑块可用键盘和触摸查看年度金额。

## 迁移到其他平台

未来把 `investmentEngine.ts`、`investmentTypes.ts`、`investmentValidation.ts` 作为独立模块复用即可。平台层只负责读取输入、将百分数转为小数、调用引擎、消费结构化数据和格式化结果。其他币种只需替换格式化层；图表可直接使用 `chartData`。不需要移植 React 组件，也不需要在新平台重新实现金融模型。

当前不包含小红书 API、平台适配、币种切换、税费、通胀、不规则现金流、月度明细、账户或持久化功能。
